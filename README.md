# Ferma Animalelor
Acesta este proiectul meu pentru cursul de POO.

Jocul Ferma Animalelor este un life simulation game în care jucătorul 
își duce traiul printre animăluțele fermei, acesta poate întreprinde 
diferite activități precum agricultura și negoțul, își poate utiliza
capitatul pentru a investi în bursa de valori a fermei sau pentru a cumpăra
diverse obiecte. Obiectele pot fi dobândite și prin interacțiunea cu celelalte
animale.
Jucătorul are următoarele stats-uri: HP, intelligence, guts, charm - ce pot fi
modificate de obiectele căpătate și balance și social credit, cel dintâi modificându-se 
prin tranzacții, iar cel din urmă se modifică în funcție de alegerile jucătorului pe
parcursul jocului și îi condiționeaza posibilitatea de a întreprinde anumite acțiuni
În funcție de nivelul stats-urilor se pot debloca diferite scenarii de sfârșit joc.
